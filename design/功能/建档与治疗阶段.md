# 建档与治疗阶段

**状态**：已实现　·　**在原型里看**：首次使用：欢迎 → 选择阶段 → 再填 2 项 → 准备好了

## 对应思维导图

- 问题点：如何循序渐进地让患者上传自己的个人信息，在不繁琐的同时收集必要信息，同时逻辑清晰。以及对刚刚开始治疗佩戴支具的患者提供鼓…
- 构想：信息页功能
- 构想：年龄&骨龄
- 问题点：脊柱侧弯治疗有不同的治疗周期
- 构想：发现侧弯：分析度数，定制支具。理想情况在月经开始之前（也就是身高定型之前）
- 构想：上传初始资料，年龄也要纳入分析
- 构想：康复期：支具+运动，重点在于长期的支具佩戴和高强度运动
- 构想：患者的生长发育期逐渐停止，脱掉支具以运动为主。这段时期脊柱的度数会反弹，旋转患者反弹程度更大。
- 构想：贯穿整个青春期，患者在学业和身体上面临很大压力，需要关注心理因素，难以坚持

## 现在的做法

- 首次只问出生年月和性别，性别可自定义
- 五个阶段：刚发现侧弯还在检查 / 刚开始戴支具（前两周）/ 支具 + 运动训练 / 已脱支具以运动为主 / 成年后自我管理
- 「再填 2 项」：初潮情况（还没有 / 已经来了 / 不想填）和手头有哪些资料（检查报告、处方单）
- 「准备好了」页按阶段给不同的鼓励；刚戴支具的人看到适应期说明
- 阶段随时可在「我的 › 切换阶段」修改，首页内容跟着变

## 已定的规则

- 不区分青少年 / 家长身份，只问年龄和性别
- 不在第一次使用时要求上传全部资料，之后随复查逐步补全
