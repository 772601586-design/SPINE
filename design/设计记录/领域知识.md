# 领域知识与设计规范

做 Spine 时用到的医学背景、一份示例处方的结构，以及 demo 的视觉规范。医学内容仅供产品设计参考，以医生和康复师的意见为准。

## 医学背景

- **保守治疗**：不手术，靠支具和运动控制侧弯的进展。关键窗口是生长发育期，理想情况是在初潮前、身高定型前发现并干预。
- **治疗阶段**：
  - 发现侧弯后检查分析度数、定制支具。
  - 康复期：支具 + 高强度运动，以长期佩戴支具为重点。
  - 生长发育停止后：逐渐脱支具，以运动为主。这一时期度数会反弹，旋转明显的患者反弹更大。
  - 成年后：自我管控、终身坚持、改善体态。
- **Cobb 角**：衡量侧弯度数，有大约 ±5° 的测量误差，两次复查相差 5° 以内不代表真的变化。
- **Risser 征**：从 X 光看骨骼成熟度（0–5），用来判断还剩多少生长空间。
- **初潮**：女孩生长高峰的参考指标；初潮后生长速度逐渐放缓。
- **Rigo 分型**（施罗斯体系常用）：A 型为三弯，B 型为四弯，E 型为单弯。下面还有细分（如 B1）。分型决定矫正动作的方向。
- **施罗斯（Schroth）疗法**：按弯型个性化的三维矫正训练，配合定向呼吸（往凹侧吸气、矫正时吹气）。同一个动作，弯型不同，方向可能相反，所以不能用通用视频库。
- **支具**：每天要戴够医生规定的时长（常见 18–23 小时）。可以用温度传感器自动记录佩戴时间。常见困扰包括前两周适应期、皮肤压红、压着肚子吃饭不舒服、经期不适，以及学校里体育课和同学的眼光。

## 一份示例运动处方的结构（已去除个人信息）

来源于一份 2025 年的运动处方（Rigo B1），用来设计卡片与排卡逻辑。具体动作因人而异。

| 模块 | 动作 | 参数 | 频率 |
|---|---|---|---|
| 认知学习 | 画脊柱弯型图 | 每天 10 张 | 每天（产品中改为社群里的每周挑战） |
| 姿势矫正 | 右臀承重坐；撑杆站立 | 撑杆 3 分钟 | 每天 |
| 柔韧 | 猫—骆驼；右弓箭步拉伸左髂腰肌 | 2 分钟；30 秒 × 2 | 每天 |
| 3D 矫正 | 强化运动 · 肋木（使劲吹气）；肌肉圆柱 | 各 5 分钟 | 每天 |
| 核心 | 卷腹仰卧自行车；平板支撑；右侧桥；臀桥；Y-W-T | 50 × 2；3 分钟；3 分钟；100 × 2；各 30 × 3 | **隔天** |
| 颈椎 | 7 个小动作 | 约 5 分钟 | 每天 |
| 拉伸放松 | 跪位 / 坐位前伸；悬吊配合呼吸 | 各 2 分钟；3 分钟 | 每天 |
| 辅助运动 | 蛙泳 | 30 分钟，心率 130–150 | 每周 3 次 |

从处方里能识别出三种播报节奏：**计时**（平板支撑 3 分钟）、**计数**（臀桥 100 个 × 2 组）、**呼吸**（强化运动配合吹气）。

## demo 视觉规范

- 画板尺寸 390 × 844（手机），圆角 28。
- 字体：Noto Sans SC。
- 颜色：

| 用途 | 色值 |
|---|---|
| 页面背景 | `#F3F5F2` |
| 主色（青绿） | `#1F6F66` |
| 浅青绿底 | `#DDEDE9` |
| 强调色底 / 字（橙，松果等） | `#F6DCC8` / `#6B3416` |
| 正文 | `#1F2A27` |
| 次要文字 | `#5B6663` |
| 跟练深色背景 | `#143F3A` / `#0E1513` |

- 语气：温和、不制造焦虑，少用数字倒计时和排名。勋章只看坚持，不看度数。
