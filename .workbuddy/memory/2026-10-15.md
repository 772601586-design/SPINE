## 修复 rehab/index.wxml 编译错误（Bad attr `wx:if` unexpected `}`）

- 根因：`pages/rehab/index.wxml` 第 14 行 `wx:if` 表达式里逻辑与写成了 HTML 实体 `&amp;&amp;`（文件真实字节如此），WXML 编译器解析不了，报 `Bad attr wx:if ... unexpected }`（14:17）。
- 修法：把 `&amp;&amp;` 换回 `&&`（WXML 属性里直接写 `&&` 即可）。已全局扫描其他 .wxml 的 `{{}}` 表达式，无同类实体残留。
- 教训：编辑 wxml 表达式时不要对 `&` 做转义；若再见到 `unexpected }` 报错，先用 Python 看原始字节，Read 工具看到的可能就是原样实体。

## 同一类问题共 3 处（onboarding/profile、treatment-stage、rehab）

- `pages/onboarding/profile/index.wxml:6` `index &lt;= stepIndex` → 报 `Bad attr class ... unexpected ';' at pos9`
- `pages/treatment-stage/index.wxml:5` `!loading &amp;&amp; revision` → 报 `Bad attr wx:if ... unexpected ';' at pos13`
- 机理：**WXML 编译器在 `{{}}` 内不做 HTML 实体解码**，表达式解析器把 `&lt;` 读成 `&` + `lt` + `;`，因此报 `unexpected ';'`（`&amp;` 则表现为 `unexpected }` / `;`）。
- 结论：`{{}}` 里必须写**裸运算符**——裸 `&&`、裸 `<=` 都是合法的（本地 `pages/rehab/follow/index.wxml` 一直用裸 `<`、`>=` 且编译正常，可作参照）。
- 已全量复查 `miniprogram/**/*.wxml`：表达式内无实体、无 NBSP/全角空格/零宽字符，属性值内无实体；三个文件的标签闭合结构校验通过；`tsc --noEmit` 0 error。
- 复查脚本（可复用）：Python 遍历 rglob('*.wxml') + 正则 `\{\{(.*?)\}\}` 检查 `&amp;/&lt;/&gt;/&quot;/&#/\u00a0/\u3000/\u200b/\ufeff`。
