# 专题 06｜心理成长（mental-growth）

> 与「00-总纲」一起使用。`risk_level` 建议 `high`（涉及情绪与治疗依从）。

## 读者与场景

孩子不愿穿支具、不愿脱衣服、不愿被同学看到；家长说"我们都是为你好"，越说越僵。也有人度数不大，却一直很在意背部的样子。

情绪基调：**不评判、不鸡汤、给话术**。承认难受是真实的，再给可操作的做法。

## 必答问题

1. 身体形象为什么重要？它和度数是什么关系？
2. 戴支具一定会让孩子更自卑吗？
3. 孩子不肯戴，是意志力问题吗？
4. 家长可以说什么、不说什么？
5. 什么时候需要找心理专业人员？
6. 怎么和学校、同学打交道？

## 可用来源与关键事实

| source_id | 可支撑的事实 |
|---|---|
| `PSYCH2018` | 身体形象是侧弯患者心理社会困难中最重要的环节；自我报告的身体形象与治疗结果显著相关；侧弯与情绪障碍、进食行为的关系因测量工具差异而不明确，需要更多研究 |
| `BODYIMAGE2016` | BrAIST 女性样本随访 2 年：戴支具组与观察组在身体形象和生活质量上无显著差异；身体形象越差，生活质量越差（与治疗方式无关）；转组者和 Cobb ≥40° 者自我身体形象更差 |
| `NHSUK2023` | 侧弯或戴支具可能带来身体形象与自尊方面的困难，尤其对儿童青少年；支持团体有帮助 |
| `NIAMS2023` | 戴支具可能让孩子害羞；如孩子拒绝佩戴，应与医生讨论其他支具或治疗方案；支持团体可帮助应对 |
| `BRAIST2013` | 佩戴时长与成功率正相关——依从性是疗效变量，不是道德问题 |
| `AAOSNONSURG2024` | 支具类型选择应让孩子参与决策，因为"只有按医嘱佩戴才有效" |

## 写作禁区

- 不写"想开点就好了""别人比你更惨"。
- 不把不戴支具归因为"不懂事""不自律"。
- 不诊断抑郁、焦虑、进食障碍；只写"如果持续……建议寻求专业帮助"。
- 不承诺"戴支具不会影响心理"——研究说的是组间平均无差异，个体差异很大。

## 三个选题

1. **身体形象：被侧弯改变的，不只是背**（分类：情绪与成长）
   核心：身体形象是心理负担的核心，也与生活质量强相关；但"戴支具必然毁掉身体形象"没有证据支持。
2. **戴支具被同学问起，怎么回答**（分类：情绪与成长）
   核心：可以选择解释、可以选择不说；准备一句短话术；提前和老师沟通；把"被看见"的主动权拿回来。
3. **焦虑、坚持和"我不想戴了"：家庭怎么合作**（分类：情绪与成长）
   核心：依从性靠计划、沟通和支持，不靠责备；让孩子参与决策；把目标从"今天几小时"换成"这周怎么排"。

## 验收标准

- 出现"身体形象与生活质量相关"和"支具组与观察组平均无显著差异"两个结论，并说明后者是群体平均。
- 给出 2—3 句家长可以直接说的话术（示范句）。
- 明确写出求助信号：情绪持续低落、回避上学、睡眠饮食明显改变、自伤念头 → 尽快寻求专业帮助。
- 全文不出现"坚强点""别在意"这类否定感受的句子。
