# 专题 02｜影像检查（imaging）

> 与「00-总纲」一起使用。

## 读者与场景

拿到报告单，看到"Cobb 角 28°""Risser 3""建议随访"，不知道哪个数字重要。也有人担心"拍这么多次片子会不会得癌"。

情绪基调：**把数字翻译成决策**。不制造"度数焦虑"，也不敷衍。

## 必答问题

1. Cobb 角是怎么量出来的？为什么两次能差几度？
2. 差多少度才算真的加重？
3. 为什么要拍站立位全长片？躺着拍行不行？
4. 多久拍一次？拍多了有辐射风险吗？
5. 报告上除了 Cobb 角还要看什么？（弯曲位置、骨成熟度、旋转、平衡）
6. 什么时候需要做 MRI？

## 可用来源与关键事实

| source_id | 可支撑的事实 |
|---|---|
| `COBBVAR1990` | 同一批片子、不同测量者，平均差 3.8°；95% 的差异 ≤8°；要有 95% 把握认为变化真实，差异需 ≥10° |
| `AAOSNONSURG2024` | 现代 X 线已把儿童剂量降到很低；多数孩子每年因侧弯拍片的辐射量低于本底辐射和一次飞行的量级；观察期 6—12 个月复查；已停止生长者可能不再需要拍片 |
| `AAOSAIS2024` | X 线用于确定弯曲位置与严重程度；复查间隔 6—12 个月 |
| `EOSDOSE2019` | 在儿童体模上，EOS 的器官剂量最低；部分 CT 定位像协议低于传统投影摄影，但总体上传统摄影与 CT 定位像高于 EOS |
| `SOSORT2016` | 评估是保守治疗的第一环，共 14 条评估推荐 |
| `NIAMSTX2023` | X 线是最常用的诊断检查，用于测量弯曲程度 |

## 写作禁区

- 不写"辐射可以忽略，随便拍"；也不写"拍片会致癌"。
- 不给"必须每 3 个月拍一次"这类固定频率，频率由医生按生长阶段与进展速度决定。
- 不把 Risser 征写成家长必须掌握的知识，点到"骨成熟度评估"即可。

## 三个选题

1. **Cobb 角差 3 度，是变严重了吗**（分类：看懂检查结果）
   核心：量角本身有误差；3—5 度的波动常见，10 度以上才更像真实变化；看趋势不看单点。
2. **拍片会不会有辐射风险：多久拍一次才合理**（分类：看懂检查结果）
   核心：现代设备剂量低，但仍应"该拍才拍"；观察期通常 6—12 个月；可询问是否有低剂量设备；保留旧片便于对比。
3. **报告上除了度数，还有四个词值得看懂**（分类：看懂检查结果）
   核心：弯曲位置、骨成熟度、椎体旋转、冠状面平衡——它们共同决定"会不会加重、要不要治疗"。

## 验收标准

- 明确写出"3.8°""10°"这两个数字及其含义，并说明是测量者间差异。
- 全文不出现"辐射无害"与"辐射致癌"两种极端表述。
- 给出一个可执行动作：复诊时带上次的片子，要求同一体位、同一设备测量。
