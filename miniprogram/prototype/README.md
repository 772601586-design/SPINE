# 完整原型体验

此分包完整复现 `spine1/demo/miniprogram` 的 18 个页面及演示交互。真实功能保留在主包中。

- 登录页或「我的」→「完整 demo 体验」，不需要登录或后端。
- 所有页面顶部标记「示例数据 · 非本人处方」，可返回真实功能。
- 演示状态使用独立的 `spine.prototype.state.v1` 键；重置只清除此键。不会修改真实档案、处方、打卡或本机录像。
- 原型中的处方/报告识别、视频、传感器、社群、小测、奖励均按原型演示，不代表真实服务、他人内容或医学建议。
- 五个底部入口使用分包内导航，真实小程序的五个 Tab 保留。其他页面使用小程序原生返回。

生成：在 `miniprogram` 运行 `npm run sync:prototype`。这会覆盖此分包的生成页面和核心代码，不会修改真实功能。修改原型内容应先改设计源，再重新生成；页面增加时需同步主包 `app.json` 的分包路由。

检查：`npm run check:prototype` 检查页面完整性、原始内容与业务逻辑一致性、脚本流程、随机点击、导航、重置隔离，以及演示入口与真实登录的异步竞争；`npm run check:wxml` 检查主包与分包所有表达式。

编译模式可直接指定页面：`prototype/pages/welcome/index`。已建过演示档案时会进入演示今日；可在演示「我的」底部重置。
