## 怎么用

### 1. 批量导入（草稿）

```powershell
cd backend
.\.venv\Scripts\python.exe manage.py import_knowledge "..\02-稿件\knowledge-topics.zip" --user 编辑账号 --report preview.json
.\.venv\Scripts\python.exe manage.py import_knowledge "..\02-稿件\knowledge-topics.zip" --user 编辑账号 --commit --report import.json
```

### 2. 在小程序里预览（未审核）

```powershell
cd backend
$env:KNOWLEDGE_PREVIEW_DRAFTS='true'
.\.venv\Scripts\python.exe manage.py runserver 127.0.0.1:8000 --noreload
```

不带这个变量时，公开接口只返回"已发布 + 已审核"的文章，专题页为空。

### 3. 不做 App 也能看

直接打开 `05-预览/知识库专题文章预览.html`，含目录、全文与每篇的来源链接。

## 状态与边界

| 项目 | 状态 |
|---|---|
| 稿件内容 | 完成（16 篇，约 1500—2000 字/篇） |
| 来源 | 14 条，均有 DOI/PMID 或机构页面；全部"未核对" |
| 医学审核 | **未做**。没有审核记录，没有审核人签字 |
| 小程序展示 | 依赖 `KNOWLEDGE_PREVIEW_DRAFTS=true`，列表与详情显式标注未审核 |
| 配图 | 无。所有文章纯文字，避免素材授权问题 |
| 中文来源 | 未取得可公开核对的原文，暂未收录 |

## 版权说明

- 稿件是中文原创表述，只引用事实与数字，文末给原文链接，**没有复制段落、表格或图片**。
- 整篇翻译、整段搬运、直接转贴（即使标注来源）**不属于**本交付包的做法，需要逐篇取得授权后才能做。
- 美国政府作品（NIH/NIAMS）多属公有领域；NHS 内容多为 Open Government Licence；AAOS OrthoInfo 保留版权，只能改写+链接。详见 `04-文档/知识库专题文章与权威来源.md`。

## 要上线还差什么

1. 补「重要结论 → 正文位置 → 原文定位」；导入器不生成这些关系。
2. 独立医学审核账号核对来源与逐条证据（不能是编辑本人）。
3. 审核通过后由管理员发布；发布后不再依赖预览开关。
