# 训练计划、动作库、跟练与支具联动

更新时间：2026-10-13

## 本轮代码差异

- 康复首页原有“动作与运动”卡片保留；点击后现在直接打开“我的训练计划”。原来位于该页的分段占位和支具入口已移除，康复首页的支具入口保留。
- 新增 `training` Django 应用：个人训练计划、不可变计划版本快照、个人动作卡及参数历史、训练尝试、单组确认记录和支具结束提示事件。
- 动作库已补“＋ 添加到计划”；登录用户重复添加相同资源版本会返回现有卡，不重复创建；目录接口能显示本人是否已添加。
- 动作卡必需参数为空时保存为“待设置”；填好组数、剂量及方向后，需用户明确核对才可开始。后端二次检查，不依赖前端禁用按钮。
- 跟练页按用户确认逐组写入 PostgreSQL；实际组次可编辑；服务端按用户请求 UUID 幂等，重复组号和重复请求不能重复累计。提前结束标记部分完成。
- 支具结束只在存在活动计划、可开始动作卡且没有其他活动训练时创建一次提示事件；用户可记录“查看计划”或“暂时不用”。不会替用户开始训练或更改支具区间。
- 已登录用户筛选支持区域、主/次肌群、目标、体位、器材和一般/专项类型。内容后台可维护动作资源版本；公共目录仍只呈现有审核者、审核日期且状态为发布的版本。
- 动作类别与“需个体设置”已迁到 `ExerciseVersion`，不再附着于动作稳定身份；新增数据迁移会先复制旧值再删除旧列。已发布版本内容不可原地保存修改，需创建新版本；后台提供区域、肌群、目标及资源版本管理。

## 外部动作资源核验

核验日期：2026-10-13。页面用于决定资源管理方式，不是将其内容导入库。

- [AAOS Spine Conditioning Program](https://www.orthoinfo.org/recovery/spine-conditioning-program/) 提供目标肌群、器材、动作步骤等内容结构，并明确建议按个人情况与医生/治疗师讨论。
- [AAOS Linking Policy](https://www.orthoinfo.org/about-orthoinfo/linking-policy/) 允许直接链接到 OrthoInfo 页面，但明确禁止把其材料复制或改编后发布。因此本项目只保存来源链接，不复制动作步骤、图片或视频。
- [RNOH Scoliosis Physiotherapy](https://www.rnoh.nhs.uk/services/scoliosis/conservative-management-scoliosis/outpatient-scoliosis-physiotherapy) 页面可用于分类框架参考；本次未找到可复用其媒体或全文的授权声明，不复制内容。
- [Schroth scoliosis exercises](https://schrothmethod.com/scoliosis-exercises/) 本轮打开时停留在验证码页面，内容与授权均未核实。
- [PSSE 七大体系综述](https://pmc.ncbi.nlm.nih.gov/articles/PMC4973373/) 本轮页面访问被拦截，未核实全文使用许可。

所以目前没有预置公开动作，也没有把相似动作、方向或剂量猜成处方。管理员只有取得授权并完成内容审核后，才应发布资源。当前媒体播放只支持已审核目录数据中显式提供的音频/视频链接；动态语音播报、个人示范/指导录音的私密录制上传尚未接通。
