# 个人账号与支具记录 · 开发联调

> 历史说明：此文记录 Flutter 客户端阶段的接口与操作。个人端现已改为原生小程序；当前导入、会话、环境配置与验收以[微信小程序启动与验收](./微信小程序启动与验收.md)为准。本文保留作接口和迁移参考。

本轮使用实际目录 `backend` / `flutterapp`，保留原四入口和基础接口。所有支具、佩戴、感受接口仅访问本人记录，没有 staff 绕过、专业共享或默认目标。

## 1. 当前数据库与账号

当前数据库为项目内 PostgreSQL 17.11：二进制 `.tools/postgresql/pgsql`，数据 `.tools/postgresql-data`，日志 `.tools/postgresql.log`。这些目录已被忽略，不能删除数据目录或重新初始化来排错。数据库不是系统服务，电脑重启后需启动。
密码从 `backend/.env` 读取，未输出到日志。应用角色非超级用户，开发测试具有 CREATEDB 权限。
开发账号是 `spine_a` / `spine_b`，共同的本机开发密码在 `.env` 的 `SPINE_DEV_PASSWORD`。不要公开此文件。创建命令仅在 DEBUG 模式运行，不覆盖已有账号或密码。

```powershell
cd D:\SPINE\backend
.\.venv\Scripts\python.exe local_postgres.py start
.\.venv\Scripts\python.exe manage.py migrate --noinput
.\.venv\Scripts\python.exe manage.py create_dev_accounts
.\.venv\Scripts\python.exe manage.py check
.\.venv\Scripts\python.exe manage.py runserver 127.0.0.1:8000 --noreload
```

已连通的现有数据库优先保留；`local_postgres.py start` 不会重新初始化它。若配置指向远程数据库，直接按该数据库操作，不运行本地实例替代它。首次在其他电脑运行需安装 PostgreSQL，或取得官方 Windows 二进制放在上述目录。
当前沙箱 pg_ctl 的信号操作受限；不要用任务结束或删数据目录代替正常数据库关闭。普通终端可尝试 `local_postgres.py stop`，失败时保持实例运行并检查日志。

访问 `http://127.0.0.1:8000/api/v1/ready/` 必须返回 200、`database=ok`。它检查真实连接，但不代替迁移检查。业务联调不用 `--skip-migration-check`。

## 3. 页面逐步验收

1. 打开“今日”，在“支具与感受记录”输入 `spine_a` 和本机开发密码，点“登录”；显示当前用户。
2. 点“新增支具”，填名称，可填类型、机构、日期、备注，保存。可用“编辑支具”修改档案或停用；停用后不能新增佩戴，但既有记录保留。
3. 点“已戴上”，看到服务器保存的开始时间及“佩戴中”。切到“社区”，再回“今日”，应重新读取并恢复同一记录。点“刷新记录”也会从后端读取。
4. 点“已取下”，区间结束并进入历史。双击被页面禁用；网络失败后可重试，后端不会改变已成功保存的结束时间。
5. 点“补录佩戴”，按上海时区填写 `YYYY-MM-DD HH:mm`。用一个没有其他记录的日期，填 23:30 到次日 01:00，应分别显示 30、60 分钟。时间也允许带秒和时区。
6. 在该历史记录点“修正”，将结束改为次日 02:00，填写原因，保存；统计应更新为 30、120 分钟。“修改历史”显示原区间、新区间、备注变化和原因。冲突时取消弹窗、刷新记录后再修正。
7. 补录一条与已有区间重叠的记录，应显示 HTTP 409；结束早于/等于开始、未来时间等应显示 HTTP 400。失败记录不会持久化。
8. 点“记录感受”，痛感留空，填身体位置、标签、发生时间和备注，可选择同一支具的佩戴记录。保存后显示“痛感：未填写”。再保存一条痛感 0 的记录，显示“0 分”。位置/标签支持顿号或逗号分隔；点历史感受可编辑。照片本轮未接入。
9. 点“退出登录”，再以 `spine_b` 登录。B 看不到 A 的支具或任何私人记录。通过修改记录 ID 越权读取或更新会被后端拒绝。
10. Flutter 令牌只在内存：切换四入口保持登录；刷新网页、重启 App 会丢失本地令牌，需要重新登录。再次登录后记录及未结束状态仍从数据库恢复。服务端退出撤销旧令牌；没有宣称持久登录。

无记录显示“暂无记录；不代表零佩戴”。未结束记录只统计到请求时刻；跨日计算固定上海时区。统计包含本人所有支具，不计算达标、不生成医疗结论。

## 4. API 契约

认证头：`Authorization: Token <token>`；登录返回 token 与 `{id, username}`。Token 不放 URL，不在日志输出。

| 方法与路径 | 行为 |
|---|---|
| POST `/api/v1/auth/login/` | username、password；错误凭证 400，有开发限流 |
| POST `/api/v1/auth/logout/` | 撤销本人 Token，204；旧令牌后续请求 401 |
| GET `/api/v1/auth/me/` | 当前个人账号 |
| GET/POST `/api/v1/braces/` | 本人支具列表、新增 |
| GET/PATCH `/api/v1/braces/{id}/` | 本人档案读取/编辑 |
| POST `/api/v1/wear-sessions/start/` | brace、request_id(UUID)，可选 started_at；省略时使用服务器时间 |
| POST `/api/v1/wear-sessions/{id}/end/` | 可选 ended_at；省略使用服务器时间；重复结束保持原时间 |
| GET/POST `/api/v1/wear-sessions/` | 本人历史/补录；补录要求 brace、request_id、started_at、ended_at |
| GET/PATCH `/api/v1/wear-sessions/{id}/` | 读取/修正；修正传 version、reason，以及要改的时间/备注 |
| GET `/api/v1/wear-sessions/{id}/revisions/` | 只读前后快照及原因 |
| GET `/api/v1/wear-sessions/statistics/` | `{timezone: Asia/Shanghai, days: [{date, seconds, minutes}]}` |
| GET/POST `/api/v1/comfort-entries/` | 本人感受历史/提交；brace、request_id、occurred_at，pain可空，positions/tags数组，notes，wear_session可空 |
| GET/PATCH `/api/v1/comfort-entries/{id}/` | 本人感受读取/编辑；不能修改 request_id |

创建佩戴及感受的同一次失败重试必须复用 UUID，不能复用该 UUID 提交不同内容。创建成功 201，幂等重放 200；冲突 409。修改佩戴由版本号避免覆盖并发修正。
支具归属由后端决定；关联佩戴必须属于本人及同一支具。其他用户的详情/修正/历史返回 404，列表与统计按本人过滤。
数据库约束单用户只允许一条未结束佩戴；区间不重叠，边界相邻允许。后端事务锁串行校验不同支具的记录。后台直接写表也需使用业务服务，不能绕过区间检查。

## 5. 自动验证

```powershell
cd D:\SPINE\backend
.\.venv\Scripts\python.exe -m pip check
.\.venv\Scripts\python.exe manage.py check
.\.venv\Scripts\python.exe manage.py makemigrations --check --dry-run
.\.venv\Scripts\python.exe manage.py test core braces --noinput --keepdb
.\.venv\Scripts\python.exe manage.py spectacular --validate --file NUL
# 需要后端已在 8000 运行；创建独立验证账号及明确标记的测试记录，保留既有数据。
.\.venv\Scripts\python.exe verify_flutter_client.py
```

`verify_flutter_client.py` 默认使用当前已发现的 SDK；其他机器设置 `SPINE_DART_EXE` 指向 Flutter SDK 的 `bin/cache/dart-sdk/bin/dart.exe`。它不输出密码/Token；真实使用 `flutterapp/lib/api.dart`，不使用模拟服务。
单元/并发测试运行在独立的 `test_spine` 数据库中；`--keepdb` 保留测试库，业务 `spine` 不被清空。

普通终端仍应补充 `flutter analyze`、`flutter build web`、页面点击和 Android/iOS 实机验收。本次浏览器自动化连接失败，不能把客户端 HTTP 验证当作页面已验收。
